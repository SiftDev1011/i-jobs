i-jobs engine API (0.1.0)

The job engine behind i-jobs by 99, Remote Hustle and School1.

One API serves three kinds of caller:

  • The i-jobs app (and its owner dashboard) calls with a user's access token.
  • Partner sites (Remote Hustle, School1, future sites) call from their own servers with their site key. To act for one of their users they add X-Site-User with that user's id on their site.
  • Staff tools call the /admin endpoints with a staff user's access token.

Conventions

  • Money is an integer in the smallest unit (amount_minor: kobo for NGN, cents for USD).
  • Times are ISO 8601 in UTC.
  • Lists use cursor paging: pass cursor from the previous page's next_cursor.
  • Errors use application/problem+json. The code field is stable; build on it, not on title.
  • Creating payments, applications or code batches needs an Idempotency-Key header, so a retried request never charges or applies twice.

AI work and the daily budget

i-jobs runs on Groq's free tier, which caps tokens per day. Endpoints that need AI (CV parsing, apply packs, posting a pasted job, support answers) never fail because of this. They return 202 Accepted with status: scheduled and a scheduled_for time when today's budget for that task is spent. Show the user "Scheduled for tomorrow" and listen for the matching webhook or notification.

Prices

Public endpoints never return community prices or i-jobs' share. A member sees their own community's price only at the payment step (GET /join/{code}). The ₦5,000 minimum and the share are only returned to verified owners.
